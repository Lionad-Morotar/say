261007 修复记录（Lionad 试听驱动）

① frieren-zh 音源找错人：原 20.8s B 站中配 raw 窗主说话人是村长（男声）——「我想请你解读这本书」是问芙莉莲的话。取窗内 11.62-14.86s 芙莉莲独句（3.24s）重采。
② voxcpm 长参考失稳（引擎约束，非资产缺陷）：>10s 参考致零样本克隆塌形——ref-en 14s → 男声（F0 108-113Hz vs 参考 185Hz，可复现），dva 28s → 无浊音；≤10s 全正常。角色资产三窗规整（ja 10.0 / en 8.4 / dva 9.0），修复后 F0 对拍 183Hz ✓。GPT-SoVITS 的 3-10s 硬限在 VoxCPM 上同样成立，早期调研只做指标复核未做人工听感，漏抓。
③ lucy 干净源：htdemucs_ft 4 模型集成重分离，取 5.0-12.3s 露西连续两句（7.3s）；官方 Lucy 特辑（日英混剪）与 Drive Like Hell（枪战短句）验证后弃用。
④ default 性别标注纠偏：gptsovits/indextts default = 官方示例男声（早期版本标"中性"无依据），firered default = 女声，voxcpm = 指令随性别；sherpa 有 45 个 zm_* 中文男声（"男声仅 system 可达"为误断）。
⑤ ja 进域接线：detectTextLang 假名优先三值化；firered shim <|Japanese|> 映射；locale/config 三元化，ja → gptsovits + frieren 内置预设；协议文档语种面更新；测试覆盖 121+ 用例（引擎四套件 115 + 渲染器 6 全绿）。
