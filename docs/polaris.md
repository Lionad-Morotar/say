# 北极星目标（Polaris）

> 本文件定义项目的长期愿景。北极星循环据此发散性创造 epic，跃进式选择开发方向。

## 好听的 agent 说话体验（替代 macOS say）

* 愿景描述：全局 CC 工作流已允许 agent 在情绪表达时用 bash `say` 说话，但 macOS 内建音色机械、不好听。目标是获得一个音色自然（神经网络级）、语气节奏可定制的 TTS CLI，无缝替换现有 `say` 工作流。音色人格化（用户中途补充）：默认音色为用户指定角色（芙莉莲 / D.Va / 2077 Lucy）的克隆音色，说话语言以英语为主，中文仅在克隆与合成质量达标时启用。路线优先级（用户已表态）：接口完全一致的 say alias > 现成新 CLI > 套壳开源 TTS 项目自建 CLI > 从头自研。
* 验收信号：
  - agent 工作流中的说话命令产出明显优于 macOS 默认音色的听感（用户主观试听验收通过）
  - 默认音色为芙莉莲 / D.Va / Lucy 之一的克隆音色（英语），用户试听认可角色相似度；中文音色仅在用户试听判定「非常完美」时启用，否则不承诺
  - 另保留英/中各至少一个通用自然音色作为备选预设
  - 短句（< 50 字）出声延迟：热调用 ≤ 3s、冷调用（首次模型加载）≤ 10s，不阻塞 agent 工作流（基线对照：本机系统 say 合成 22 字中文约 2s，最终数字由蓝图按实测钉）
  - 音色、语速、语气可通过配置或参数自定义
  - 全局 CLAUDE.md 的 say 工作流零改动或仅一行命令级改动
* 优先级：高
* 状态：active
