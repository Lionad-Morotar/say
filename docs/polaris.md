# 北极星目标（Polaris）

> 本文件定义项目的长期愿景。北极星循环据此发散性创造 epic，跃进式选择开发方向。

## 好听的 agent 说话体验（替代 macOS say）

* 愿景描述：全局 CC 工作流已允许 agent 在情绪表达时用 bash `say` 说话，但 macOS 内建音色机械、不好听。目标是获得一个音色自然（神经网络级）、语气节奏可定制的 TTS CLI，无缝替换现有 `say` 工作流。路线优先级（用户已表态）：接口完全一致的 say alias > 现成新 CLI > 套壳开源 TTS 项目自建 CLI > 从头自研。
* 验收信号：
  - agent 工作流中的说话命令产出明显优于 macOS 默认音色的听感（用户主观试听验收通过）
  - 中文与英文各有至少一个自然音色可选
  - 短句（< 50 字）端到端出声延迟 p95 < 3s
  - 音色、语速、语气可通过配置或参数自定义
  - 全局 CLAUDE.md 的 say 工作流零改动或仅一行命令级改动
* 优先级：高
* 状态：active
